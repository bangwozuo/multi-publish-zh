### 示例 1：平台格式适配

**能力**：同 4.4.1-S4（资产库级共用）


姐妹们！我发现一个能省 3 小时的工具 😭

之前每天光想选题就要 1 小时，现在打开就有 3 个选题 + 现成文案…

👉 链接放评论区了

## 已满足的约束

- [x] 字数 187 字（平台上限 1000 字）
- [x] 话题标签 4 个（要求 ≥3）
- [x] 无违禁词

## 调整说明

原内容偏书面语，改写为口语化表达；补充 emoji 提升可读性；结尾引导至评论区而非直接放外链（避免平台限流）。

### 示例 2：发布规则校验

**能力**：校验字数/图片比例/违禁词

**输入**：

```json
{
  "text": "全网最低价，包治百病，100% 有效"
}
```

**输出**：

## 扫描结果

**结论**：不通过

## 违规项

| 位置 | 原文 | 问题类型 | 修改建议 |
|------|------|---------|---------|
| 第 1 句 | 全网最低价 | 极限词 | 改为「同价位中较有优势」 |
| 第 1 句 | 包治百病 | 虚假功效 | 删除，改为具体适用场景描述 |
| 第 1 句 | 100% 有效 | 绝对化表述 | 删除，改为「多数用户反馈良好」 |

## 风险等级

**高** — 同时命中三类违规，直接发布可能被平台处罚

## 补充建议

建议补充 AI 生成内容标识；如涉及功效描述，需提供检测报告支撑。

**资产位置**：`skills/publish-rules-validate/`

### 示例 6：效果归因

**能力**：跨平台效果对比与归因分析

**输入**：

```json
{
  "data": {
    "曝光": 12000,
    "点击": 480,
    "转化": 32
  }
}
```

**输出**：

## 核心结论

本周曝光增长 62% 来自 Reddit 单帖爆发，其余渠道基本持平。

## 驱动因素

1. **Reddit 热帖** — 贡献 62% 增量，帖子进入 subreddit 首页
2. **X 转发** — 贡献 18%，主要来自 2 个 KOL 转发
3. **自然搜索** — 贡献 12%，长尾词开始见效

## 置信度

**中** — 数据来源为用户手动导出，样本周期仅 1 周
