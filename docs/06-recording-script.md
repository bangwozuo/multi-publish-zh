# 分发中控 — 演示录像脚本

> **总时长**：3-5 分钟 ｜ **用途**：产品演示视频
> **录制建议**：1080p / 30fps，字体 16pt+，深色主题

---

## 一、录制前准备

| 项目 | 准备内容 |
|------|---------|
| 素材 | 已克隆仓库、打开 `skills/` 与 `workflows/` 目录 |
| 工具 | 一个 AI 对话窗口（已粘贴好 prompt.txt） |
| 窗口 | 文件管理器 + AI 工具 + 浏览器（GitHub 页面） |
| 数据 | 准备好示例输入，避免现场打字 |

---

## 二、分镜脚本

### 镜头 1：开场（0:00 - 0:20）

**画面**：GitHub 仓库首页

**旁白**：

> "这是 **分发中控**——一次录入、十平台分发、数据自动回捞的"分发中控台"。
> 它由 5 条工作流和 6 个原子技能组成。
> 重点说一句：**这是纯提示词资产，不需要 API Key，不需要部署，复制粘贴就能用。**"

**操作**：滚动 README，停在「快速开始」。

---

### 镜头 2：它解决什么问题（0:20 - 0:50）

**画面**：`docs/03-scenarios.md`

**旁白**：

> "它服务的是需要多平台内容分发的全体独立开发者与内容创作者……
> 过去他们要花大量时间做这件事，现在可以交给它。"

**操作**：滚动使用场景表。

---

### 镜头 3：资产结构（0:50 - 1:20）

**画面**：`docs/01-architecture.md` 架构图

**旁白**：

> "结构很清晰：四层——用户、数字员工、工作流、原子技能。
> 原子技能在 skills/，工作流在 workflows/，
> 每个资产都是一个文件夹，里面有定义、提示词、规格、示例，还有它自己的一整套文档。"

**操作**：展开 `skills/` 与 `workflows/` 目录树。

---

### 镜头 4：核心演示——复制即用（1:20 - 2:40）

**画面**：文件管理器 + AI 工具

**旁白**：

> "现在演示核心用法。打开第一个技能——平台格式适配。"

**操作**：

1. 打开 `skills/platform-format-adapt/prompt.txt`
2. 全选复制
3. 切到 AI 工具，粘贴到系统提示词
4. 按输入规格提供数据

**旁白（看到输出后）**：

> "注意输出结构——它严格遵守了我们定义的格式。
> 这不是随机生成，是可控、可复用的。"

---

### 镜头 5：工作流串联（2:40 - 3:30）

**画面**：`workflows/` 下对应工作流目录 + AI 工具

**旁白**：

> "单技能只做一件事。要跑完整流程，用 workflows/ 下的工作流。
> 这是 **内容一次录入**，它把几个原子技能串起来。"

**操作**：展示 DAG 图，然后演示把上一步输出喂给下一步。

---

### 镜头 6：资产校验（3:30 - 4:00）

**画面**：终端

**旁白**：

> "最后是质量控制。我们跑一遍资产校验——
> 检查每个技能的四件套是否齐全、提示词必需区块是否完整、schema 是否一致。"

**操作**：

```bash
pytest tests/ -v
```

**旁白**：

> "全部通过。**注意：这一步不需要任何 API Key。**"

---

### 镜头 7：结尾（4:00 - 4:30）

**画面**：GitHub 首页 + Star

**旁白**：

> "仓库地址在简介里。觉得有用欢迎 Star。
> 所有资产是开源的，Apache-2.0，可以自由修改商用。"

---

## 三、后期制作要点

| 项目 | 要求 |
|------|------|
| 字幕 | 中文硬字幕 24pt+ |
| 转场 | 每镜头间 0.3s |
| 强调 | 用红框标注「无需 API Key」「复制即用」 |
| 背景音乐 | 轻电子，-20dB |
| 封面 | 员工名 + 一句话定位 + 「纯提示词资产」标签 |
| 结尾 | 停留 3 秒展示仓库二维码 |
