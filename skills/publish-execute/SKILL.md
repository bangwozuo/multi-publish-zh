# 发布执行

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_dev_05_sk04` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 分发中控 |
| 能力族 | — |
| 复杂度 | `M` |
| 阶段 | `P1` |
| 复用度 | 中（依赖外部工具） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

调用 MultiPost/官方 API 完成发布

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `schedule` | string | ✅ | 已确认的发布计划 |
| `assets` | string | ✅ | 已就绪的文案与素材清单 |

## 输出规格

发布执行

- `manifest`：逐个平台的最终物料
- `checklist`：人工发布前必须确认的事项
- `limitation`：明确声明需人工执行发布

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "schedule": "已确认排期（2026-10-09）：1. 小红书《秋季收纳好物清单（上）》2026-10-09 20:00 发布；2. 知乎《秋季收纳好物清单（上）》2026-10-09 20:30 发布；3. B站动态《秋季收纳好物清单（上）》图文版 2026-10-09 21:00 发布。",
  "assets": "已就绪物料：\n- 小红书版文案：标题《秋季收纳好物清单（上）｜60平两居室的 5 个改造动作》，正文 480 字，图片 6 张（封面 cover-xhs.jpg + 内容图 5 张），话题标签 4 个\n- 知乎版文案：标题《秋季收纳好物清单（上）：60平两居室改造实录》，正文 1,850 字，配图 4 张\n- B站动态文案：标题《秋季收纳好物清单（上）图文版》，正文 120 字，配图 3 张\n所有文案已通过发布规则校验，素材文件位于本地素材库 /assets/2026-10/"
}

```

**输出**：

## 发布前检查

1. 确认三个平台的账号均已登录，且为对应目标账号（小红书、知乎、B站各 1 个）
2. 核对小红书 6 张图片（含封面）顺序与话题标签数量（4 个）无误

4. 确认素材路径 /assets/2026-10/ 下的文件均为最新校验通过版本
5. 发布后 30 分钟内检查各平台内容是否正常展示（封面、图片、标签完整）

*AI 生成内容，发布动作需人工确认并执行。*
