# 平台格式适配 · 安装使用手册

> 本手册说明如何把该原子技能资产用起来。全程 **不需要 API Key、不需要安装任何软件**。

---

## 一、前置条件

| 项 | 要求 |
|----|------|
| AI 工具 | 任一支持自定义提示词/角色设定的工具（Coze / WorkBuddy / Dify / Claude / ChatGPT / 通义 / Kimi） |
| 算力 | 你自己的账号订阅，本资产不代付任何模型费用 |
| 数据 | 按下方「输入准备」提供的业务数据 |
| 知识库 | 可选，强烈建议（见仓库 `knowledge/`） |

---

## 二、安装（导入提示词）

| 平台 | 导入方式 | 适用形态 |
|------|---------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` | 对话式 |
| **WorkBuddy** | 新建 Skill → 指令区填入 `prompt.txt` | 资产包 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` | 工作流 |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` | 长文本 |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` | 对话式 |
| **通义 / 文心 / Kimi** | 直接粘贴到系统提示词 / 角色设定 | 对话式 |

> **要点**：`prompt.txt` 是完整提示词，**整份粘贴**，不要只取片段。

---

## 三、输入准备

| 输入项 | 说明 | 示例 |
|--------|------|------|
| 主稿 | 本资产的必需输入 | 见 `examples/input.json` |

## 四、使用方法

### 方式一：直接使用（最快，推荐）

```text
1. 把 prompt.txt 全文作为系统提示词 / 人设
2. 按「输入准备」把数据发给 AI
3. 得到结果，人工审核后使用
```

### 方式二：在平台里编排

| 平台 | 操作 |
|------|------|
| Coze / 扣子 | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` → 发布 |
| WorkBuddy | 新建 Skill → 指令区填入 `prompt.txt` |
| Dify | 新建应用 → 提示词编排 → 粘贴，或作为 Workflow 节点 |
| Claude | 新建 Project → Instructions 粘贴；可挂 Knowledge |
| ChatGPT | 新建 GPT → Instructions 粘贴；可挂 Knowledge |

---

## 五、挂载知识库（可选但强烈建议）

```text
1. 打开仓库 knowledge/ 目录
2. 按 wiki 词条模板填写你的业务信息
3. 上传到 AI 平台的知识库 / Project Knowledge
4. 重新运行，输出会更贴合你的业务
```

详见 `knowledge/README.md` 与 `knowledge/RAG-接入指南.md`。

---

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 输出太泛、不贴合 | 挂载知识库，填入真实业务信息 |
| 输出被平台截断 | 拆分任务，分两次处理 |
| 提示词被平台改写 | 检查平台的「人设」是否覆盖了系统提示词 |
| 结果不稳定 | 降低温度参数（若有），或补充输入上下文 |
| 想批量处理 | 把多条数据分批投喂，或在工作流中循环 |

---

## 七、卸载 / 迁移

本资产无安装痕迹，**删除提示词即完成卸载**；迁移只需复制 `prompt.txt` 到新平台。
