# 平台格式适配

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_dev_05_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 分发中控 |
| 能力族 | — |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | 极高 |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

同 4.4.1-S4（资产库级共用）

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content` | string | ✅ | 待处理的原始内容 |
| `target` | string | ✅ | 需要校验的对象 |

## 输出规格

改写与适配

- `adapted`：改写后的完整文本
- `changes`：逐条说明改了什么、为什么
- `constraints`：字数/标签数等硬约束的达标情况与依据

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

**输入**：


**输出**：

```markdown
## 改写结果

标题：60 平米两居室，我们花 800 元完成了全屋收纳改造

家里 60 平米，两个人住，东西越堆越多——这是我们上个月之前的常态。

上个月，我们用两天时间做了一次全屋收纳改造，总花费不到 800 元。今天把 5 个技巧分享给你。

① 竖向收纳：在衣柜内部加装层板，同样的空间能多放约 40% 的衣服。

② 抽屉分隔盒：29 元三个的那种就够用，不需要买贵的。

③ 门后挂钩：浴室门后装一排，毛巾和浴巾都能挂起来。

④ 带轮透明收纳箱：床头柜下方和床底的空间也能利用起来。

⑤ 定期清退：每季度末把一年没动过的东西装进纸箱封存，三个月后还没想起来的，就捐掉。

改造不需要大动干戈，几百块就能让家里清爽不少。

你家最乱的是哪个角落？评论区聊聊。

## 改动说明

| # | 原文要点 | 改动后 | 改动理由 |
|---|---|---|---|
| 1 | 标题为「小户型收纳改造的 5 个实用技巧」 | 改为「60 平米两居室，我们花 800 元完成了全屋收纳改造」 | 微信公众号标题宜具体化、场景化，突出面积与花费两个具体数字，提升打开意愿 |
| 2 | 五个技巧连在一个长段落里 | 拆分为 ①-⑤ 编号短句，每条独立成段 | 满足目标要求中的「段落短小」，适配手机端阅读 |
| 3 | 开头用两句长句叙述背景 | 保留原意，压缩为两段短开场 | 缩短篇幅，把字数留给技巧主体 |
| 4 | 结尾无互动设计 | 新增结尾提问「你家最乱的是哪个角落？评论区聊聊。」 | 满足目标要求中「结尾带一句互动提问」，且提问内容与原文主题一致，未引入新事实 |

## 约束核对

1. 字数：改写后全文约 340 字（含标题），满足「全文不超过 500 字」
2. 风格：段落短小（每段 1-2 行）、结尾含互动提问，符合微信公众号推文风格要求
3. 事实一致性：5 个技巧、800 元总花费、40% 衣物容量提升、29 元分隔盒等事实均来自原文，未增删事实

```
