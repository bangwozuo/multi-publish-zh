## 三、异常分支

```mermaid
flowchart TD
    A["接收输入"] --> B{"输入完整？"}
    B -- 否 --> C["列出缺失字段并追问"]
    B -- 是 --> D["执行处理"]
    D --> E{"合规校验"}
    E -- 不通过 --> F["返回违规项与修改建议"]
    E -- 通过 --> G["输出结果"]
    G --> H["人工审核"]
```

## 四、状态说明

| 状态 | 含义 | 后续动作 |
|------|------|---------|
| 待输入 | 缺少必需字段 | 补齐后重跑 |
| 处理中 | 正在生成 | 等待 |
| 待审核 | 已产出，含 AI 生成标记 | 人工审核 |
| 已定稿 | 审核通过 | 可直接使用 |

---

*原子技能为单节点流程；复合技能为多节点 DAG。*
