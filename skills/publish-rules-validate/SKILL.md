## 输出规格

合规校验

- `verdict`：是否通过 / 风险等级
- `violations`：逐项列出违规内容
- `suggestions`：针对性的改写方向

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "text": "重磅新品上线！这款收纳箱是我们全平台销量第一的爆款，好用程度堪称收纳界的天花板，100% 的用户都说好，用过的人都觉得它是市面上最好的收纳神器，现在下单还送价值 99 元的收纳袋！",
  "platform": "小红书",
  "rules": "通用广告法禁用词词表：禁用极限词（最好/第一/100%/国家级/顶尖/天花板等绝对化用语）；禁用虚假承诺与诱导性表述"
}

```

**输出**：

```markdown
## 总体判定

| 项 | 内容 |
|----|------|
| 判定结果 | 未通过 |
| 风险等级 | 高 |
| 违规数量 | 4 处绝对化用语 |
| 检查依据 | 用户提供的通用广告法禁用词词表 + 目标平台小红书营销用语惯例 |

## 违规项

| # | 违规词/表述 | 原文片段 | 违反规则 | 修改建议 |
|---|---|---|---|---|
| 1 | 第一 | 「我们全平台销量第一的爆款」 | 绝对化用语，违反广告法禁用极限词规定 | 改为「我们全平台销量靠前的热销款」 |
| 2 | 天花板 | 「好用程度堪称收纳界的天花板」 | 绝对化用语，与词表明示禁用的「天花板」相符 | 改为「好用程度在同类产品中评价很高」 |
| 3 | 100% | 「100% 的用户都说好」 | 绝对化用语 + 无法证实的用户评价承诺 | 改为「多数用户反馈使用体验良好」 |
| 4 | 最好 | 「它是市面上最好的收纳神器」 | 绝对化用语，违反广告法禁用「最好」类表述 | 改为「它是我用过的收纳箱里让我印象很深的一款」 |

## 整体修改建议

1. 将全部绝对化用语替换为可量化或主观体验类表述（如「热销」「评价很高」「回购意愿强」），避免「第一/最好/100%/天花板」等词
2. 「现在下单还送价值 99 元的收纳袋」需确保赠品信息真实，注明活动时间与数量上限，避免构成虚假承诺
3. 目标平台为小红书，平台对营销类用语审核较严，建议同时规避「爆款」「神器」等高风险词，降低限流与下架风险

---
*AI 生成内容，合规判定仅供参考，最终发布前需人工复核。*


```
