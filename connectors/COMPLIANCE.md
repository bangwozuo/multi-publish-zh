# 合规红线清单：分发中控

> 本清单适用于本数字员工及其全部技能与工作流。**红线不可逾越**。

---

## 一、绝对禁止（红线）

| # | 红线 | 说明 |
|---|------|------|
| 1 | 爬取需登录的私密数据 | 包括但不限于私域聊天、后台订单明细 |
| 2 | 刷量 / 刷评 / 刷粉 | 任何形式的虚假数据制造 |
| 3 | 协议机器人 / 绕过风控 | 包括模拟登录、破解验证码 |
| 4 | 拉踩竞品、虚假宣传 | 违反《反不正当竞争法》《广告法》 |
| 5 | 使用极限词 | 如「最」「第一」「国家级」等（《广告法》第九条） |
| 6 | 引导好评 / 删差评 | 违反平台评价规则 |
| 7 | 泄露客户隐私 | 手机号、身份证、地址、支付信息 |
| 8 | 代做资金 / 签约 / 医疗决策 | 超出资产边界且高风险 |

## 二、必须做到

| # | 要求 | 说明 |
|---|------|------|
| 1 | AI 生成内容标识 | 按平台要求声明 AI 参与 |
| 2 | 人工审核 | 所有对外内容交付前人工定稿 |
| 3 | 数据脱敏 | 个人信息先脱敏再使用 |
| 4 | 只走官方 API / 用户导出 | 数据来源必须可追溯 |

## 三、合规自检（每次使用后）

```text
□ 内容是否有虚假、夸大表述？
□ 是否使用了极限词？
□ 是否涉及客户隐私？
□ 是否已做 AI 生成标识？
□ 是否经过人工审核？
```

## 四、违规后果

- 违反平台规则的，可能导致**账号封禁**
- 违反法律法规的，可能承担**民事 / 行政 / 刑事责任**

> 合规不是负担，是入场券。
