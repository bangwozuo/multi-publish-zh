# 知识库（RAG wiki）：分发中控

> 这是一个**结构化知识库**，用于给数字员工提供「你的真实业务信息」。
> 提示词决定**怎么想**，知识库决定**想的是不是你的业务**。

---

## 一、为什么需要知识库

| 没有知识库 | 有知识库 |
|-----------|---------|
| 输出通用、泛泛 | 输出贴合你的具体业务 |
| 每次都要重新说明背景 | 背景一次录入，长期复用 |
| 容易一本正经地胡说 | 有据可依，事实一致 |

---

## 二、目录结构

```text
knowledge/
├── README.md              ← 本文件（使用说明）
├── RAG-接入指南.md         ← 切片 / 嵌入 / 召回策略
├── template.md            ← 单文件填写模板（快速上手用）
├── wiki/
│   ├── index.md           ← 词条索引
│   ├── _template.md       ← 词条模板
│   └── entries/           ← 你的词条（按主题分文件）
│       ├── 01-业务基础.md
│       ├── 02-目标用户.md
│       ├── 03-语气与人设.md
│       ├── 04-历史资产.md
│       └── 05-规则手册.md
```

---

## 三、三步用起来

```text
1. 复制 wiki/_template.md，按主题填写（或直接改 entries/ 下的占位文件）
2. 上传到 AI 平台的知识库 / Project Knowledge（见 RAG-接入指南.md）
3. 重新运行数字员工，输出会带出你的业务信息
```

---

## 四、按平台挂载

| 平台 | 方式 |
|------|------|
| Coze / 扣子 | 知识库 → 新建 → 上传文档 → Bot 中关联 |
| Dify | 知识库 → 导入文档 → 应用中引用 |
| WorkBuddy | 上传文档作为上下文附件 |
| Claude | Project Knowledge 上传 |
| ChatGPT | GPT Builder → Knowledge 上传 |
| 临时使用 | 直接把内容粘贴在对话开头 |

---

## 五、内容规范

| 类别 | 具体内容 | 更新频率 |
|------|---------|---------|
| 业务基础 | 产品 / 服务介绍、价格、卖点 | 季度 |
| 目标用户 | 客户画像、常见问题 | 季度 |
| 语气人设 | 品牌调性、常用 / 禁用表达 | 半年 |
| 历史资产 | 高表现内容、成功案例 | 月度 |
| 规则手册 | 平台规则、行业规范 | 月度 |

---

## 六、注意事项

- ⚠️ **不要**填入客户隐私数据（手机号、身份证、地址）
- ⚠️ **不要**填入未公开的商业机密
- ✅ 建议脱敏后再录入
- ✅ 定期清理过期内容
- ✅ 面向客群：独立开发者、一人公司（OPC）创始人
